Excel Format Requirements

Your Excel file must contain the following columns:

  • EMP-CODE - Employee code (must exist in database)
  • HOSPITAL NAME - Hospital name (optional, use exact name or it will be skipped)
  • SHIFT - Shift name, code, or timing (optional, e.g., "12:00 PM to 09:00 PM")

Note: At least one of HOSPITAL NAME or SHIFT must be provided for each employee.
